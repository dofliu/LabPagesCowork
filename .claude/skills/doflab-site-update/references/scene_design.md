# 場景設計指南 — 分鏡、視覺語言與實戰陷阱

> 本檔沿用自 intro-video 技能。路徑對應：`scripts/*.py` → `tools/showcase/*.py`，`assets/scene_template.html` → `tools/showcase/scene_template.html`（doflab 品牌暖色版）。

## 敘事公式(60~75 秒標準版)

| 順位 | 原型 | 秒數 | 內容要點 |
|---|---|---|---|
| 1 | **開場 hook** | 6-7 | 主題名大字 + 一句定位。粒子層 + 光環/掃光(有主視覺圖就走 `.hero-img` 滿版)。別塞細節 |
| 2 | 輸入/問題 | 6-7 | 「它吃什麼」或「解決什麼痛」— 元素飛入核心的聚合動畫很好用 |
| 3..N | **重點景 ×2-4** | 6-8 | 一景一重點(功能/成果/主題)。有真實截圖就放截圖,沒有就做「迷你 mock」(進度條、卡片、面板),不要只放字 |
| N+1 | **差異化重點(戲劇景)** | 7-8 | 全片情緒高點:前一刀用 fadeblack 切黑停頓,再用大字 + 震動 + 對比演出核心主張 |
| N+2 | 產出/成果 | 6-7 | 使用者最後拿到什麼(上傳完成、報表、徽章列) |
| 尾 | **CTA** | 6-7 | 主題名回歸 + 特點三連 + 連結/單位/聯絡方式 + 署名(有 logo 就用 `.logo`)。粒子層回歸 |

分鏡先寫成表格(景名/一句話/秒數/轉場)給使用者過目再動工 — 改分鏡便宜,改成品貴。

### 長度伸縮(30 秒 ~ 3 分鐘,先問使用者要哪種)

原則:**調景數,不拉單景** — 單景超過 10 秒會悶,節奏靠「換景」不靠「等」。

| 目標長度 | 景數 | 怎麼排 |
|---|---|---|
| **30 秒短版** | 4-5 | 開場 → 功能 ×2(挑最有感的)→ 戲劇景或產出擇一 → CTA。每景 6-7s,砍輸入景 |
| 60-75 秒標準 | 6-9 | 上表公式原樣 |
| 90-120 秒 | 10-13 | 功能景擴到 4-5 個;重點功能拆兩景(概念景 + mock 演示景);加一景「工作流程串走」(輸入→處理→產出一鏡到底的管線動畫) |
| **3 分鐘完整版** | 15-18 | 分「章」思考:開場章(hook+問題+定位)→ 功能章 ×3-4(每章 2 景:是什麼 + 怎麼動)→ 戲劇景(全片仍**只有一個**)→ 成果章(產出+數據/規模景)→ CTA。每 3-4 景換一次色調性當「換章」訊號 |

長版守則:戲劇景與 fadeblack 全片各只用一次,不因片長變多;30fps 下 3 分鐘 ≈ 5400 格,
渲染時間隨長度線性成長(約 8-10 分鐘/分鐘片長),排程時心裡有數。

## 轉場選單(xfade transition)

`fade`(通用)· `smoothleft`/`smoothup`(推進感)· `circleopen`(揭幕感,適合功能→功能)·
`fadeblack`(切黑停頓,**只用在進戲劇景前這一刀**,多用就廉價)。每刀換不同轉場,張力來自節奏變化。

## 視覺語言(模板已內建)

- 深海底色 + teal/violet 極光暈 + 網格 + 暗角;每景 `.stage` 鏡頭慢推 1→1.055。
- 大字排版:kicker(字距拉開的小標)→ h1(漸層描邊大標)→ sub。中文標題 88-112px。
- 功能景可換色調性:改 `.bg`/`.aur` 的色相(例:黑板綠、警示金)讓每景有記憶點,但保持同一暗度。
- 元素進場全用 `.in`(上浮)/`.pop`(彈出)+ `--d` 錯開 0.15-0.3s 形成節奏;數字用 count-up、
  管線用進度條、清單用逐項點亮。
- 每景結尾**停在完整構圖**(最後 1.5s 不要再有大動作),xfade 才接得漂亮。

## ⚠️ 實戰陷阱清單(每一條都真的踩過)

1. **`.in`/`.pop` 會蓋掉定位 transform**:rise/pop 動畫結尾是 `transform:none`,
   元素若靠 `translate(-50%,-50%)` 置中會在進場後跳位。絕對置中改用
   `left:50%;margin-left:-寬度一半`、`left/right 同值`、或外層 `display:flex` 置中。
2. **膠囊/徽章要 `white-space:nowrap`**,否則中文兩字會直排折行(「構圖」變「構\n圖」)。
3. **字幕列/橫幅用 `left:60px;right:60px` 定位**,別用 50%+translate(同陷阱 1)。
4. **禁外連,但本地檔案可以**:字型用系統 Noto CJK 家族、圖示用 emoji 或行內 SVG。頁面以 file://
   離線渲染,`https://` 圖片一律變白框;**放在場景 HTML 同層 `assets/` 的圖片用相對路徑則正常載入**
   (已實測)。素材先過 `scripts/prep_assets.py`,見下節。
5. **動畫從 t=0 起算**:虛擬時鐘讓 CSS animation / rAF / setTimeout 都精準,但「等待互動」的
   邏輯永遠不會發生 — 不要寫 hover/click 才觸發的東西。
6. **渲染後必看 check_*.png**:每景渲完都有 85% 時間點抽查格。逐張 Read 檢查:文字溢出?
   元素相撞?置中跑掉?修掉再用 `--only <scene>` 單景重渲,不用全部重來。
7. **Chromium 版本對不上 playwright** 時設 `CHROMIUM_PATH` 指向既有瀏覽器執行檔。
8. **同一元素掛兩個動畫類會互蓋**:`class="pop glow"` 這種寫法,兩條 `animation` 簡寫
   後者覆蓋前者 → 進場動畫被吃掉,元素**卡在 opacity:0 永遠不出現**(兩個測試 agent
   獨立踩中)。模板已內建 `.in.glow` / `.pop.glow` 合併規則保底;要疊其他動畫時,
   用逗號合併成單一 `animation` 宣告,或把發光/漂浮掛在外層包裹 div 上。

## 真實素材版位(來源資料夾有現成圖時)

模板內建四種版位,**先讀 `assets/assets_manifest.json` 的 shape 欄再決定用哪個**:

| 版位 | 適合 | 用法 |
|---|---|---|
| `.hero-img` + `.scrim` | 主視覺、現場照、大截圖 | 滿版底圖 + 壓黑層,字疊在上面。放在 `.stage` **之前**,z-index:0 |
| `.shot` | 橫圖截圖(wide) | 帶圓角邊框的「螢幕框」,置中放,寬度 1200-1500px |
| `.frame` | 直圖/方圖(tall/square) | 固定尺寸卡片、`object-fit:cover` 裁切,適合並排三張 |
| `.logo` | 識別圖 | 固定高度、`object-fit:contain`,CTA 景與開場常用 |

實戰要點:

- **亮圖當滿版底圖一定壓不住字**:白底截圖、戶外照特別嚴重。模板預設已把 `.hero-img img`
  壓到 opacity .38 + 漸層 scrim;還是看不清就降到 .25 或把 `.scrim` 的 `--scrim` 調到 .9。
  抽查格看得吃力,觀眾在手機上就是看不到。
- **圖片別硬撐寬高**:一律靠 `.shot`(等比縮)或 `.frame`(cover 裁切)。自己寫
  `width:800px;height:400px` 會把人臉和文字拉扁。
- **直式手機照不要單張置中**:1920×1080 裡兩側會空一大片。三張並排成 `.frame` 群組,
  或當 `.hero-img` 用(會裁掉上下,先看抽查格確認沒切到頭)。
- **文件截圖在影片裡讀不完**:整頁 Word/PDF 截圖縮到畫面裡字只有幾像素。把重點抽出來做字卡,
  截圖只當「有這份東西」的背景質感。
- **一景最多一個視覺主體**:滿版底圖 + 大截圖 + 三張卡片同時上,畫面就散了。
- 圖片進場一樣用 `.in`/`.pop`,但**別掛在 `<img>` 本身**——掛在外層 `.shot`/`.frame` 上,
  避免動畫 transform 與 `object-fit` 互相打架(同陷阱 1/8 的家族問題)。

## 音訊心法(踩雷後的定調)

- **先問要不要音樂**,不要替使用者決定:很多人要無聲版自己後製配樂 — 那就交無聲版,
  這是正解不是偷懶(無聲版音畫分離,後製最自由)。
- 要音樂時 **真實音樂 >> 合成**。優先請使用者提供免版稅音樂(YouTube 音檔庫等),`--music` 合入。
- 響度:音樂主導 -16 LUFS;使用者說「背景一點/小聲一點」→ `--loudness -20`。
- `--bed` 的安靜合成氛圍是「要一點聲音但沒音樂檔」的退路,不是主菜。
- 永遠不要加持續性噪聲層(嘶聲=吵感頭號來源);節奏元素寧疏勿密(0.5s 一顆 kick 會逼死人,2s 才像心跳)。
